# Portfolio de Désiré Gouba

Portfolio personnel construit avec Next.js, TypeScript et Tailwind CSS pour présenter mon profil de développeur backend / full-stack.

## Stack

- Next.js 16
- React 19
- TypeScript
- Tailwind CSS
- Framer Motion
- Lucide React

## Lancer le projet

```bash
npm install
npm run dev
```

Ensuite, ouvrez http://localhost:3000

## Scripts disponibles

```bash
npm run dev
npm run build
npm run start
npm run lint
```

## Objectif

Mettre en avant :
- mon parcours
- mes compétences backend et frontend
- mes projets personnels
- ma disponibilité pour un stage ou une opportunité professionnelle
